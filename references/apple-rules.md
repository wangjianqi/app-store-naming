# Apple metadata rules used by this skill

Last reviewed: 2026-09-16.

Always re-check current Apple documentation for time-sensitive work.

## App name

- App Store app name must be at least 2 characters and no more than 30 characters.
- Apple App Review Guideline 2.3.7 requires a unique app name.
- Do not stuff the name or metadata with trademarked terms, popular app names, pricing information, or irrelevant phrases to game search.

Official references:

- https://developer.apple.com/help/app-store-connect/reference/app-information/app-information
- https://developer.apple.com/app-store/review/guidelines/

## Subtitle

- Subtitle maximum: 30 characters.
- It should provide additional context.
- It must follow metadata rules.
- Do not reference other apps or make unverifiable product claims.

Official reference:

- https://developer.apple.com/help/app-store-connect/reference/app-information/app-information
- https://developer.apple.com/app-store/review/guidelines/

## Keywords

- Keywords field supports up to 100 bytes.
- Keywords should describe the app accurately.
- Apple states that the app is already searchable by app name and company name, so these values should not be duplicated in the keyword list.
- Other apps' names or company names are not allowed as keywords.

Official reference:

- https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information

## Searchable metadata

Apple states that an app can be searchable by:

- app name
- app subtitle
- keywords
- company name

Official reference:

- https://developer.apple.com/help/app-store-connect/create-an-app-record/view-and-edit-app-information

## Name availability

Apple states that an app name already in use within a localization cannot be used again.

A public App Store search is only a screening step. The practical final check is whether the intended name is accepted in the relevant App Store Connect app/localization workflow.

Official reference:

- https://developer.apple.com/help/app-store-connect/create-an-app-record/add-a-new-app
