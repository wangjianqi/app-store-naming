# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),

## [1.0.0] - 2026-09-16

### Added

- `SKILL.md`: full naming workflow (CREATE / EVALUATE / RENAME / VERIFY / LOCALIZE modes), evidence discipline, and Level A/B/C availability ladder.
- `references/apple-rules.md`: current Apple metadata rules with official links.
- `references/scoring-rubric.md`: 100-point scoring rubric with hard gates.
- `references/availability-check.md`: public collision scan, trademark screen, and App Store Connect verification procedure.
- `references/aso-framework.md`: metadata allocation framework (name / subtitle / keywords / developer name).
- `templates/naming-report.md`: naming report template.
- `scripts/validate_metadata.py`: deterministic offline validator for app name, subtitle, and keyword-field constraints.
- `agents/openai.yaml`: Codex agent interface config.
- Bilingual documentation (English `README.md` + `README.zh-CN.md`), MIT license.
